Open Style Atlas

One subject, 猫耳の冒険者と男性剣士, in 100 styles, drawn by open image models, each prompted in its own language. The styles follow Style Atlas by SSSS⚡CRYPTOMAN, which draws them with ChatGPT. A style that fails is part of the result. Better prompts are welcome as pull requests.

Built with Style Atlas's blessing, as an independent project. Source and pull requests: github.com/codelynx/open-style-atlas.
